# 星智碰

NFC 智能鼠标垫「星智碰」的 H5 页面。**碰一下鼠标垫上的卡片，手机就打开这个页面**——
不装 App、不扫码、不输网址。

**线上地址：** https://zengfujei-code.github.io/xingzhipeng/

## 四个入口

| 地址 | 场景 |
| --- | --- |
| `/` | 首页，三张卡片入口 |
| `/?s=plan` | 学习计划 |
| `/?s=homework` | 作业管家 |
| `/?s=ask` | 随问随答 |

这四个地址就是写进 NFC 卡里的四个入口。

## 关于 index.html

**单文件，没有构建步骤**——`index.html` 就是线上跑的那一份，改完直接替换、推上来即可。

页面上的回答来自**讯飞星火**，经由腾讯云函数转发。密钥不在前端，也不在这个仓库里，
只存在云函数的环境变量中。

## ⚠️ 这个仓库必须保持公开

上面那个 Pages 地址被**写死进了四张 NFC 卡**。
GitHub 免费版的 Pages **只服务公开仓库**——一旦把仓库转成私有，站点会立刻 404，
**卡片就打不开了**。

所以请不要：改可见性、改默认分支、把 `index.html` 挪进子目录、删掉这个仓库。

## 改版记录

每次改完 h5 都会推一条「同步提交件」，说明这一轮改了什么、怎么验证的。
推上来之后 GitHub Pages 会自动重新构建。
